Body face specimens

Every candidate set in real Qala copy at production sizes: card title 17 semibold, body 14.5, stats with numerals, a right-aligned load column, buttons, an 11px group label, and an italic hint line. Row 0 is today (DM Mono body) for contrast. All files below are the Google Fonts latin woff2 I measured with fontTools; facts, not brochure copy. DM Sans was cut before specimens: it ships proportional-only digits with no tnum, so stat columns and ticking numbers would wobble.

How this was measured. Files are the Google Fonts latin woff2 for each face (via Fontsource, same bytes Google serves). fontTools read the fvar axes, the GSUB feature list, OS/2.sxHeight, and the advance widths of 0–9. Licenses confirmed as license: "OFL" in each family's upstream METADATA.pb. Full upstream variable TTFs were checked where the subset lacked tnum: Recursive, Source Sans 3, and DM Sans have no tnum even upstream, but Recursive and Source Sans ship tabular-by-default digits with pnum, so alignment needs no CSS. DM Sans is proportional-only and was cut.
