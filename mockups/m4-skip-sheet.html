Skip sheet

Reason, the injured muscle only when injured, a note, a span. It opens from "Skip today" on Today and from any unlogged day in Plan. Copy follows DESIGN 7.18: each reason says what happens (rests, shifts, guards) and nothing counts against you. A skip is never a miss, so there is no warning color, no count and no confirm-away dialog; Today has Undo.

Two states for each option

Row one is Sick, this day only (the common case). Row two is Injured for 7 days, which adds the muscle picker. Everything is tappable. The injured state in A starts with no muscle picked, so you can see the disabled Skip button; B and C start with Quads picked.
